# Crypto Market Advisor

**Локальный аналитик рынка криптовалютных перпетуалов — не торговый бот.**

Приложение читает рынок, само считает всю математику, отдаёт готовые признаки локальной LLM,
пропускает её ответ через детерминированный risk engine и выдаёт вам рекомендацию.
Сделку совершаете вы. Приложение ведёт учёт и оценивает качество собственных прошлых прогнозов.

## Что это делает

```
рыночные данные + публичные новости  →  локальная нормализация и дедуп
        ↓
индикаторы · свечные и графические паттерны · структура рынка · уровни · дивергенции · режимы
        ↓
исторический контекст: статистика прошлых решений, похожие случаи
        ↓
компактный snapshot  →  локальная LLM  →  строгая валидация схемы
        ↓
детерминированный risk engine (последнее слово о плече и размере — за ним)
        ↓
рекомендация  →  ваше решение  →  ручной учёт позиции  →  фактический результат
        ↓
статистика, которая войдёт в следующий анализ
```

LLM — только слой интерпретации. Она не получает цены сама, не считает ни одного индикатора и не
отправляет ордера: каждое число, которое она видит, посчитал backend.

## Чем это не является

* Приложение **не** открывает, не закрывает и не изменяет позиции.
* Приложение **не** отправляет ордера на биржу.
* Приложению **не** нужны приватные API-ключи. Используются только публичные endpoints.
* Приложение **не** выдумывает данные. Недостающие признаки помечаются как `degraded`, а
  отклонённый ответ модели сохраняется как ошибка, а не показывается сигналом.

Вы торгуете вручную. Приложение записывает, что вы действительно сделали, и измеряет, насколько
хорош был его совет.

## Главное

| | |
|---|---|
| **Всё локально** | Postgres, backend, UI и (по желанию) сама модель работают на вашей машине. Ни аккаунта, ни телеметрии, ни стороннего сервиса, который знает о ваших позициях. |
| **Математику считает backend** | ~25 индикаторов, ~45 свечных и 20 графических формаций, структура рынка со свингами и BOS/CHoCH, кластеризованные уровни, дивергенции RSI/MACD/OBV и классификатор режима — всё детерминированно и покрыто тестами. |
| **Последнее слово не за моделью** | Отдельный risk engine заново считает допустимое плечо и размер позиции по волатильности, расстоянию до стопа, режиму, уверенности и качеству данных. В интерфейсе видно и предложение модели, и итог. |
| **Строгая валидация ответа** | Проверяются enum'ы, диапазоны, направление TP/SL и суммы долей закрытия. У некорректного ответа ровно одна попытка починки, после чего он становится сохранённой ошибкой inference. |
| **Есть с чем сравнивать** | Взвешенные стратегии с жёсткими вето выносят собственный вердикт на каждом цикле и сохраняются рядом с ответом модели: «LLM против правил» проверяется на одной истории. |
| **Честный бэктест** | В момент T движок видит только свечи ≤ T — это закреплено регрессионными тестами. Моделируются комиссии, funding, проскальзывание, частичные исполнения, ликвидация и maintenance margin. |
| **Учёт только вперёд** | Деньги — `decimal` на всём пути. Результат позиции выводится из исполнений и не переписывается; прогноз не редактируется после того, как стал известен исход. |
| **Три языка** | Английский (по умолчанию), русский и упрощённый китайский, включая текст самой модели: одна рекомендация на трёх языках, сгенерированная за один inference. |

## Быстрый старт

**Нужно:** Docker с Compose v2. Для встроенной модели — ещё NVIDIA GPU с Container Toolkit.
Go 1.25+ и Node 22+ нужны только для локальной разработки.

```bash
git clone https://github.com/crypto-market-advisor/advisor.git
cd advisor
cp .env.example .env
# отредактируйте .env — как минимум комиссии вашего тарифа, см. docs/configuration.md

docker compose up -d                  # frontend + backend + postgres
# или, вместе с локальным llama.cpp:
docker compose --profile llm up -d
```

Интерфейс: <http://localhost:3000>, состояние: <http://localhost:8080/api/health>.

При первом запуске приложение применит миграции, создаст настройки по умолчанию, загрузит топ-20
торгуемых активов из CoinGecko (без stablecoins и wrapped/staked дубликатов), наполнит историю
свечей, начнёт сбор публичных RSS/Atom и объявлений Bybit и покажет состояние всех зависимостей в
шапке.

**Без модели тоже работает.** Если LLM выключена или недоступна, сбор данных и весь технический
анализ продолжаются, в шапке появляется соответствующий статус, а рекомендации просто не
генерируются. Выдуманных сигналов приложение не показывает никогда.

Ярлыки: `make up`, `make up-llm`, `make down`, `make logs`, `make migrate`, `make test`,
`make lint`, `make frontend-test`. Каждый — это одна команда `docker compose` или `go`/`npm`, они
перечислены в [Makefile](Makefile) для тех, у кого `make` нет.

## Как этим пользоваться

| Задача | Где |
|---|---|
| Добавить или отключить актив | **Рынки → Добавить актив** (идентификатор CoinGecko + символ). Ручные правки переживают ежедневное обновление топ-20. |
| Запустить анализ прямо сейчас | **Рынки → Запустить анализ**, с защитой от спама (`ANALYSIS_MANUAL_COOLDOWN`). |
| Записать реальную сделку | Кнопка «Открыл сделку» на карточке рекомендации или на странице актива. Размер можно задать количеством, номиналом или маржой — остальное вычислится. |
| Сопровождать позицию | Частичное закрытие (25/50/75/100% от остатка), полное закрытие, правка TP/SL, ручной ввод комиссии и funding. Каждая операция дописывается в неизменяемую историю. |
| Проверить модель | **История** и **Статистика**: win rate, profit factor, expectancy, MFE/MAE, просадка и калибровка уверенности — действительно ли заявленные 90% сбываются в 90% случаев. |
| Проверить идею | **Бэктестирование**: детерминированный режим для длинных периодов, LLM-режим для сравнения решений шаг за шагом. |

Рекомендации не уничтожаются: «удалить» — это мягкое скрытие, при котором прогноз, inference, ваше
решение и исход остаются в базе и в статистике.

## Настройка за минуту

Всё лежит в [`.env`](.env.example), с комментариями и по группам. В первый день важны три вещи:

```env
# 1. Комиссии — намеренно пустые. Придуманная ставка молча исказит ваш P&L.
DEFAULT_MAKER_FEE_PCT=
DEFAULT_TAKER_FEE_PCT=

# 2. Где модель. Встроенный llama.cpp или любой OpenAI-совместимый сервер.
LLM_BASE_URL=http://llm:8080/v1
LLM_MODEL=Qwen3-8B
LLM_MAX_CONCURRENT_REQUESTS=1

# 3. Сколько процентов капитала может стоить срабатывание стопа.
RISK_PER_TRADE_PCT=0.75
```

Пока обе ставки не заданы, комиссия считается неизвестной, в интерфейсе висит предупреждение, а все
затронутые суммы помечены как приблизительные. Настройки, изменённые в UI, хранятся в базе и имеют
приоритет над `.env`, чтобы перезапуск не откатывал их; чтобы вернуться к окружению, запуститесь
один раз с `SETTINGS_FROM_ENV=true`.

Полный справочник: **[docs/configuration.md](docs/configuration.md)** (документация на английском).

## Источники данных

Только публичные endpoints, без авторизации:

* **Bybit V5 Market Data** — каталог spot-инструментов, тикеры, нативные OHLCV с оборотом и история
  расчётов funding. Основной источник цены и свечей.
* **CoinGecko** — капитализация и её ранг, которых нет ни на одном биржевом endpoint, а значит и
  автоматический топ-20. Источником свечей он не является: актив, которого нет на Bybit,
  помечается как неторгуемый, а не анализируется по приближённым барам.
* **Новости** — объявления Bybit плюс RSS/Atom (по умолчанию Ethereum Foundation, CoinDesk,
  Cointelegraph). Conditional GET, ограничение размера ответа и защита от SSRF на редиректах и при
  установлении соединения.

Новость никогда не задаёт направление: реакция рынка на событие недетерминирована, поэтому свежее
критическое событие может только ограничить вход, но не аргументировать сторону.

## Приватность и безопасность

* Ни приватных ключей биржи, ни отправки ордеров, ни доступа к счёту — так устроено, а не настроено.
* Секреты остаются в `.env`, который в `.gitignore`; в браузерное хранилище ничего чувствительного
  не пишется.
* Ответ модели считается недоверенным вводом: он разбирается, валидируется, ограничивается risk
  engine и никогда не выполняется как код.

## Дисклеймер

Это аналитический инструмент. Его прогнозы не гарантируют движение цены, прошлые измерения не
переносятся на будущее, и каждая сделка — ваше решение и ваш риск. Это не инвестиционный совет.
